# Hard Stone Tracker — Fabric 26.2

[![Build mod](https://github.com/ArchDwarf/hard/actions/workflows/build.yml/badge.svg)](https://github.com/ArchDwarf/hard/actions/workflows/build.yml)


Клиентский мод для Hypixel SkyBlock: HUD со статистикой добытого Hard Stone и топ игроков по коллекции.

## Что умеет
- **Счётчик блоков**: считает каждый добытый тобой Hard Stone (камень) в Dwarven Mines, Crystal Hollows и Glacite Mineshaft. Локация определяется автоматически через `/locraw` (ответ скрывается из чата).
- **Реальный дроп**: парсит сообщения `[Sacks] +N items` и суммирует строки `Hard Stone` — это количество с учётом Mining Fortune.
- **Блоков/час**, активное время с авто-паузой при простое (по умолчанию 60 с).
- **Рекорды**: лучший блоков/ч, статистика за всё время, топ-10 твоих лучших сессий.
- **Топ Hypixel** через официальный API (нужен только ключ): мод берёт официальный лидерборд `/v2/leaderboards`, находит доску Hard Stone, подтягивает ники и коллекцию `HARD_STONE` лидеров. Если у Hypixel такой доски нет — топ строится по твоему списку игроков (`/hs top add`).
- Всё сохраняется в `config/hardstonetracker.json`.

## Команды
| Команда | Что делает |
|---|---|
| `/hs` | статистика сессии и за всё время |
| `/hs reset` | сохранить сессию в историю и начать новую |
| `/hs sessions` | твои лучшие сессии |
| `/hs top` | топ игроков по коллекции Hard Stone |
| `/hs top boards` | показать официальные лидерборды Hypixel (SkyBlock/майнинг) |
| `/hs top board <path>` / `auto` | выбрать доску вручную / автопоиск Hard Stone |
| `/hs top add <ник>` / `remove <ник>` / `clear` | свой список игроков (запасной вариант) |
| `/hs top refresh` | обновить топ (автообновление — раз в 10 мин) |
| `/hs apikey <ключ>` | Hypixel API-ключ |
| `/hs hud` / `/hs hud top` / `/hs hud pos <x> <y>` | настройки HUD |
| `/hs afk <сек>` | через сколько секунд простоя ставить таймер на паузу |
| `/hs anywhere` | считать камень где угодно (для теста в одиночке) |
| `/hs help` | список команд |

## Hypixel API-ключ (для топа)
1. Зайди на https://developer.hypixel.net, войди через аккаунт Hypixel-форума.
2. Создай Development Key (он действует ~3 дня, потом нажми «Regenerate»).
3. В игре: `/hs apikey <ключ>`.
4. У игроков в топе в SkyBlock должен быть включён API «Collections» (SkyBlock Menu → Settings → API Settings).

## Сборка .jar
### Вариант 1 — без установки чего-либо (GitHub Actions)
1. Создай репозиторий на GitHub и загрузи туда содержимое этой папки.
2. Вкладка **Actions** → workflow «Build mod» запустится сам.
3. Через ~3–5 мин открой запуск → **Artifacts** → скачай `hardstone-tracker-jar`.

### Вариант 2 — локально
Нужен JDK 25. В папке проекта:
```
gradlew build        (Windows)
./gradlew build      (Linux/macOS)
```
Готовый файл: `build/libs/hardstone-tracker-1.0.0.jar`.

## Установка
Положи `.jar` и **Fabric API** для 26.2 в папку `.minecraft/mods`, запусти профиль Fabric Loader 26.2.

## Если сборка падает
- Версии в `gradle.properties` (loader / fabric_version / loom) обнови на актуальные с https://fabricmc.net/develop/.
- Мод использует официальные имена Mojang (26.x не обфусцирован). Если в новом билде Fabric API что-то переименовали — ошибка компиляции укажет точную строку.

## Как считаются блоки
- **Блоки** — мод каждый тик сравнивает камень вокруг тебя (радиус 6). Засчитывается каждый исчезнувший блок рядом с тем, по которому ты бьёшь (ЛКМ или способность на ПКМ), и цепочки соседних блоков. Поэтому учитываются **Mining Spread** и способности вроде **Pickobulus** — всё, что ломается за один удар. В HUD видно `+N за удар`.
- **Коллекция (API)** — самый точный показатель: прирост коллекции `HARD_STONE` по Hypixel API с начала сессии. Учитывает Mining Fortune, Spread и всё остальное. Обновляется раз в 2 мин, у Hypixel задержка 1–5 мин. Нужен `/hs apikey`.
- **Дроп (сакс)** — сумма из сообщений `[Sacks] +N items`.

## Ограничения
- Если рядом (в 5 блоках от твоего блока) в ту же секунду копает другой игрок, его блоки могут попасть в счётчик блоков. Счётчик «Коллекция (API)» от этого не зависит.
- Мод только читает информацию и ничего не автоматизирует.
